Put simple drum `.wav` samples in this folder for internal playback.

Required filenames:

- `kick.wav`
- `snare.wav`
- `hihat_closed.wav`
- `hihat_open.wav`
- `tom_high.wav`
- `tom_mid.wav`
- `tom_low.wav`
- `crash.wav`
- `ride.wav`

For the first fast-testing setup, only `kick.wav` and `snare.wav` are enough.
